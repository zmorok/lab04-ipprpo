# Лабораторная работа № 5 — вариант 5: доставка еды

Проект продолжает лабораторную № 4: Maven, JUnit, Git и Jenkins Pipeline.

## Выполнено

- `OrderService.arrangeDelivery(customer, dishes, deliveryAddress)`: оформление доставки с сохранением адреса.
- SLF4J + Logback: `INFO` — успешное оформление, `WARN` — некорректные данные / нехватка средств, `ERROR` — непредвиденный сбой хранилища.
- Журнал выводится в консоль и `target/logs/application.log` (директория `target` игнорируется Git).
- Checkstyle 3.6.0 проверяет основной и тестовый Java-код: табуляции, длину строки (140), обязательные фигурные скобки, пустые операторы, звёздочные импорты (кроме static).
- Jenkins: Checkout → Build → Static Analysis → Test → Package. Дополнительная GitHub Actions-проверка не заменяет Jenkins.

## Локальные команды (JDK 23 + Maven)

```bash
mvn compile
mvn checkstyle:check
mvn test
mvn package
```

`DeliveryLoggingTest` запускает успешный и проблемные сценарии, проверяет уровни логирования и сохранность баланса при ошибке.

## Демонстрация неуспешного Static Analysis

В любом Java-файле в `src/main/java` создайте строку длиннее 140 символов, например чрезмерно длинный однострочный комментарий. Затем выполните `mvn checkstyle:check`: появится нарушение `LineLength`, сборка завершится ошибкой. После удаления длинной строки повторная проверка пройдёт. Если отправить ошибочный commit в отслеживаемую Jenkins ветку, этап `Static Analysis` завершится неуспешно, а этапы `Test` и `Package` будут пропущены. После исправления и push повторный Pipeline должен завершиться успешно.

Для демонстрации на отдельной ветке можно использовать ветку `lab05/checkstyle-failure-demo`. В Jenkins Job c `Pipeline script from SCM` временно выберите эту ветку, затем переключитесь на `main`. Срабатывание автоматического запуска зависит от настройки триггера Jenkins.

**Внимание:** Jenkinsfile использует `sh` и рассчитан на Linux/Unix-агент, как и исходная ЛР №4. Для Windows-агента необходимо использовать `bat` вместо `sh`; JDK 23 и Maven должны быть доступны на Jenkins-агенте.
